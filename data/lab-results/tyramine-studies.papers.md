# Tyramine — papers used / reviewed

Output: `tyramine-studies.json` (86 foods, 338 rows, 19 excluded). All values were read in this session from Europe PMC full-text XML tables, one supplementary PDF (Pawul-Gruba 2025 Table S1, from the Europe PMC supplementaryFiles endpoint), and the EFSA 2011 PDF (local copy from the Wayback snapshot used for histamine). Values stored as mg/100 g = mg/kg ÷ 10; `mgPerKg` holds the reported value in mg/kg (for mg/100 g papers it is ×10, stated in the description). mg/L for liquids is treated as mg/kg. Not detected / below LOQ = 0, with the limit in the description where the paper states it.
